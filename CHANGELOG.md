# Changelog

## 0.4.0 beta

- Skip unchanged persistence while preserving real transitions and audit evidence.
- Add lightweight authenticated status summaries and on-demand cycle details;
  preserve the existing full-state API and all retained records.
- Retain card/image identity, lazily load findings and retained captures, and
  preserve nested disclosures, focus and manual-review drafts.
- Serialize polling, reject superseded responses and reduce hidden-tab polling.
- Preserve recognition, selection, release and deletion safeguards; ARM overlay
  and experimental media transfer remain unchanged.

## 0.3.8 beta

- Analyze independent episode clusters, duplicate playlist/stream signatures and
  combined playlist segment unions before unknown-disc main-feature selection.
  Clear movie/TV structures can rip while recognition continues; genuine playlist
  ambiguity waits. Editorial identity and ascending episode mapping stay separate.
- Retained-scan analysis is read-only and explicitly distinguishes original extracted
  source IDs from current technical candidates.
- Authenticated, preview-bound Delete run for finalized detained/failed jobs, with
  typed job-ID confirmation, registered-file inventory/fingerprints, shared/released
  file protection, partial-failure audit and explicit user-driven recovery.
- ARM overlay v7 guards the installed database-only job deletion service with GUID,
  finalization, process and ownership checks; queue/drive readiness is verified.
- Experimental media transfer is not included in this stable beta.

## 0.3.7 beta

- Manual review: actual extracted durations before labeled scan estimates, honest
  unknowns, stable source IDs, candidate-first ordering, collapsed editable short
  clips and expandable actual paths.
- Relevant masterlist suggestions with matching/missing/contradictory evidence;
  persistent per-cycle confirm/reject/reconsider and retained reference provenance.
- Confirmed identity prepares editable, explicitly assumed source-order mappings
  and backend filename/destination previews without inference or publication.
- Existing correction submission retains partial release, completion/collision
  checks and proposal/final assignment audit history. Stale preview responses cannot
  authorize a different edited payload.
- Sanitized helper-only GHCR build; external compatible ARM overlay remains required.

## 0.3.6 beta

- TV metadata reconciliation, duration-filtered source selection and ascending
  source-to-episode mapping with scoped short-episode exceptions.

## 0.3.5 beta

- Audio work/track reconciliation, lossless-tag preparation and detained review.
